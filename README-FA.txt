Mobile369 Staff for Android 10+ — Android Studio project

وضعیت: سورس قابل کامپایل؛ فایل APK از پیش ساخته نشده است.
این نسخه پوسته اندرویدی امن برای صندوق وردپرسی موجود است، نه برنامه مستقل با API جدید.

پیش نیازهای سرور:
1. افزونه Mobile369 Smart POS نسخه 2.0 در وردپرس فعال و ووکامرس راه‌اندازی شده باشد.
2. یک برگه وردپرس با نشانی https://mobile369.ir/pos/ بسازید و [mobile369_pos] در آن قرار دهید.
3. برای هر کارمند حساب وردپرس جداگانه با نقش Mobile369 cashier/repairer/stockkeeper تعریف کنید.
4. SSL معتبر و HTTPS ضروری است. وارد کردن رمز در برنامه فقط از طریق صفحه ورود وردپرس انجام می‌شود.

ساخت APK:
1. پوشه پروژه را با Android Studio باز کنید (با اتصال اینترنت برای دریافت Gradle و Android SDK).
2. JDK 17 و Android SDK API 35 را تنظیم و Gradle Sync کنید.
3. Build > Build APK(s) را برای نسخه آزمایشی انتخاب کنید.
4. برای انتشار میان کارکنان: Build > Generate Signed Bundle / APK و امضای release را ایجاد کنید؛ فایل امضا را امن نگه دارید.
5. APK نهایی را روی گوشی Android 10 یا بالاتر نصب کنید. برای توزیع داخلی از لینک امن یا MDM استفاده شود.

محدودیت‌های مهم:
- چاپ از دکمه بالای برنامه با Android Print Framework انجام می‌شود؛ چاپ مستقیم روی چاپگرهای SII یا Gainscha نیازمند بررسی سازگاری یا SDK سازنده است.
- دوربین فقط در صفحات HTTPS سایت Mobile369 و پس از اجازه کاربر در اختیار فرم بارکد قرار می‌گیرد؛ بارکدخوانی به پیاده‌سازی سایت هم وابسته است.
- قابلیت آفلاین به معنی ثبت قطعی فروش نیست. در قطع اینترنت فروش باید تا تأیید سرور معلق بماند.
- مسیر /pos/ باید در وردپرس واقعاً ایجاد شود. اگر آدرس صفحه چیز دیگری است مقدار BASE_URL در MainActivity.java را تغییر دهید.
- این نسخه در محیط Android واقعی و هاست زنده آزمایش نشده است. قبل از راه‌اندازی عمومی، روی دستگاه واقعی تست کنید.
- برای نصب روی تمام کارکنان، نصب همان APK کافی است و هر نفر با حساب وردپرس خود وارد می‌شود.
